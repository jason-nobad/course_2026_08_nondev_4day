## 검증 체크리스트 작성 팁

- "무엇이 통과인가"를 산출물보다 먼저 정의합니다 — 기대 출력 예시, 필수 항목, 금지 표현.
- 각 항목에 **통과 예시 1개 / 실패 예시 1개**를 붙입니다.
- 실습 주제 카탈로그(`../Docs/02_practice_topics.pdf`)의 "주의할 위험·핵심 포인트"가 체크리스트 재료입니다.
- 결과는 숫자로 남깁니다: "통과 3/4, 실패: 오류 샘플에서 멈추지 않음".
