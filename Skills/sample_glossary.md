# 우리 팀 용어집 — 구매팀 (샘플)

> 📎 **샘플(가상 사례)** — 1일차 과제 "우리 팀 용어집 초안"의 예시입니다. AI는 우리 회사 말을 모르므로, 스킬에 붙여 넣을 용어를 여기에 모읍니다. 실습 시 본인 팀 용어로 바꾸세요.

| 용어 | 뜻 | AI가 흔히 하는 오해 · 주의 |
|------|------|------|
| **PO** | 구매 주문(Purchase Order). "PO 발행"은 발주가 확정되어 협력사에 전달됐다는 뜻 | 우체국(Post Office)이나 제품 책임자(Product Owner)로 읽지 않도록 |
| **PR** | 구매 요청(Purchase Request). 현업 부서 → 구매팀 | GitHub의 Pull Request와 철자가 같다. 보고서 맥락에서는 항상 "구매 요청" |
| **MRP** | 자재 소요계획(Material Requirements Planning). 매월 초 확정, 발주의 근거 | — |
| **단가계약** | 협력사별 연 단위 단가 합의. "갱신"은 만료 전 재계약 서명 | "단가 인상"과 혼동 금지 — 갱신은 조건 유지가 기본 |
| **L/T** | 리드타임(Lead Time). 발주부터 입고까지 걸리는 기간 | 단위는 일(日). "L/T 14"는 14일 |
| **로트(Lot)** | 같은 조건으로 생산된 자재 묶음. 품질 이슈는 로트 번호로 추적 | 예: 로트 2607 = 2026년 7월 생산분(가상 규칙) |
| **대체품** | 품질·수급 문제로 기존 자재 대신 검토하는 자재. 품질팀 검사 통과 후에만 발주 | "대체품 검토 중"은 발주 확정이 아님 |
| **협력사 평가표** | 분기별 협력사 납기·품질·가격 평가 양식 | — |
| **지연** | 계획 대비 **1주 이상** 늦어진 항목. 반드시 사유·재조정 일정 병기 | "진행 중"과 구분: 계획 안에 있으면 진행 중 |
| **경영지원본부 주간 회의** | 매주 월요일. 팀 주간 보고 중 팀장이 발췌한 항목만 올라감 | 초안 단계에서는 절대 공유 대상 아님 |
