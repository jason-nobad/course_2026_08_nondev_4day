# 스킬: 전자문서산업계 애로사항 접수 및 정책건의

## 1. 목적과 사용자

- **목적**: 전자문서산업계의 애로사항을 접수·분석하여 정책 건의 등의 형태로 해소한다.
- **사용자(결과물을 받는 사람)**: 산업계 회원사(애로사항 제출자), 협회 내부 이사회(의사결정권자), 국회·과학기술정보통신부 등 정책 상대방, 언론(결과 확산 대상)

## 2. 입력

- 산업계 애로사항 (간담회·유선·대면·온라인 접수 내용)
- 관련 법령·유사 선례
- 현황조사 자료, 관련 법규정
- TF 논의 결과 및 산업계 의견 수렴 결과

## 3. 작업 절차

1. **애로사항 접수·청취**: 간담회 참석, 유선 문의 응대, 대면 미팅, 온라인 상시 접수(표준 양식)로 애로사항을 수집하고 접수 대장에 기록한다.
2. **법령·선례 검토**: 관련 법령 저촉 여부를 확인하고 유사 선례를 검색하여 처리 방향 초안을 세운다.
3. **현황조사 및 내부 의사결정**: 현황을 조사하고 관련 법규정을 분석한다. 필요 시 TF를 구성해 산업계 의견을 수렴·정리하고, 보고서를 작성해 이사회에 보고한다.
4. **정책건의·대외 협의**: 정책건의서를 작성하고 국회, 과학기술정보통신부 등 유관기관과 협의한다.
5. **결과 공유·홍보**: 처리 결과를 공청회 등으로 공유하고, 언론 보도자료를 작성·배포한다.
6. **처리 현황 갱신**: 각 단계 종료 시점마다 접수 대장의 처리 현황을 갱신하여 건의인이 진행 상황을 조회할 수 있도록 한다.

## 4. 출력 형식과 완성 기준

- [ ] 애로사항이 접수 대장(표준 양식)에 기록되었는가
- [ ] 법령 저촉 여부와 선례 검토 결과가 메모로 남아 있는가
- [ ] 현황조사 보고서가 이사회 승인을 받았는가
- [ ] 정책건의서가 국회·과기정통부 등 대상 기관에 실제로 전달되었는가
- [ ] 처리 결과가 건의인(회원사)과 공유되었는가 (공청회·보도자료 등)
- [ ] 접수 대장의 처리 현황이 최신 상태로 갱신되었는가

## 5. 우리 팀 용어집

| 용어 | 의미 |
|---|---|
| 애로사항 | 산업계가 겪는 규제·제도상의 어려움 |
| 정책건의 | 법령·제도 개선을 요청하는 공식 문서 |
| TF | 특정 안건 해결을 위해 한시적으로 구성하는 조직 |
| 처리 현황 | 애로사항 접수부터 결과 공유까지의 진행 단계 기록 |
| 옴부즈만 | 정부 측 규제 애로 전담 창구(예: 중소기업옴부즈만) |

## 6. 금지 행동

- **사실관계·법령 미확인 상태에서 정책건의서를 제출하지 않는다.** (이유: 신뢰도 저하 및 협회의 정책 신뢰성 훼손)
- **이사회 승인 없이 대외(국회·언론 등)에 공식 입장을 공표하지 않는다.** (이유: 협회 공식 입장과 배치될 위험)
- **회원사 식별 정보를 비식별 처리 없이 외부에 공유하지 않는다.** (이유: 개인정보·영업비밀 보호)
- **접수 대장에 기록하지 않은 애로사항은 정책건의 절차로 진행하지 않는다.** (이유: 처리 이력 누락 방지, 건의인 조회 기능 보장)
