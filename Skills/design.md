# 스킬: 국회 위원회 홈페이지 스타일 웹 디자인 (공공기관 정보 포털)

> **근거:** https://science.na.go.kr:444/cmmit/main/main.do 2026-08-18 실측 분석 (HTML·CSS 원본 소스에서 추출한 실제 값 — `default.css`, `style.css`, `content.css`, `new_main.css`, `main.css`, `mobile.css`)
> **활용:** 정부·공공기관·협회형 정보 포털(공지·일정·게시판·자료실 중심)을 만들 때 참조. **국회 로고·엠블럼·기관명·공식 문구를 복제하지 말고 디자인 원칙만 참조할 것** (국가 상징 무단 사용 금지).

## 1. 목적과 사용자

- **목적:** 신뢰감(공공기관)과 정보 탐색 효율(다량의 게시판·일정·자료)을 동시에 주는 위원회형 정보 포털을 만든다.
- **받는 사람:** 법안·예산·회의록 등을 찾는 국민·기자·관계 기관 실무자 — 첫 화면에서 "오늘 무슨 일정이 있고, 무엇이 새로 올라왔는지"가 한눈에 읽혀야 한다.

## 2. 색상 팔레트 (CSS에서 추출한 실제 값)

| 역할 | 값 | 사용처 |
|------|------|------|
| 주 색상(--primary) | `#08216E` | 활성 탭, 버튼, 포커스 테두리, 주요 강조 텍스트 |
| 레거시 네이비(구버전 병용) | `#0C2B80` | 일부 탭 active 상태, 보도자료 카테고리 뱃지 테두리·텍스트 |

| 링크·호버 강조 블루 | `#006bce` / `#056ccf` | 본문 링크, 메뉴 호버·active, "더보기" 화살표 |

| 페이지 배경(콘텐츠 랩) | `#EDF4F1` (옅은 민트그레이) | `.MainWrapper` — 순백색이 아닌 은은한 색조 배경 |
| 라인·보더 | `#EAEAEA` / `#e9e9e9` / `#ddd` / `#dedede` | 카드 구분선, 헤더 하단 보더, 푸터 상단 보더 |
| 본문 텍스트 | `#000000` 제목 / `#666` · `#727678` 보조 텍스트 | 제목은 순검정, 캡션·푸터는 회색 |
| 다용도 카테고리 팔레트 | `#d44107` `#722f96` `#576170` `#986433` `#c18307` `#e16890` `#339966` `#8181ff` `#333dae` `#940909` `#568602` `#003e7d` `#828303` `#962f6e` 등 다수 | 일정 라벨(`.label_name`)처럼 게시판·행사 유형별 색상 구분에 사용되는 대형 팔레트 (한 페이지에 전부 쓰이지 않고, 콘텐츠 유형마다 1개씩 배정) |

**규칙:** 페이지 기본 톤은 **네이비(신뢰) + 옅은 민트그레이 배경**이며, 유채색은 링크·상태 표시에 쓰는 블루 계열로 제한한다. 카테고리 라벨처럼 "다량의 항목을 색으로 구분해야 하는 경우"에만 넓은 팔레트를 항목당 1색씩 배정해 쓴다 — 화면 전체를 다색으로 뒤덮지 않는다.

## 3. 타이포그래피

| 용도 | 서체 | 특징 |
|------|------|------|
| 본문 전체 | **Noto Sans KR 커스텀 4단계** (`NotoKrL` 100/Light, `NotoKrR` 300/Regular, `NotoKrM` 500/Medium, `NotoKrB` 700/Bold) | 자체 `@font-face`로 이름을 새로 붙여 사용 — 표준 고딕 계열 |
| 섹션 제목(H2) | NotoKrB 28px, **letter-spacing 5px**, **상단에 3px 실선(`#393939`) 오버라인** | 밑줄이 아니라 "위에 선을 긋고 자간을 넓게 벌린 소제목" — 이 사이트의 시그니처 헤딩 패턴 |
| 강조 디스플레이(선택적) | `Jalnan` (둥근 임팩트 서체) | 이벤트성 강조 문구에 한정 사용, 본문에는 쓰지 않음 |
| 메뉴 | NotoKrM 17–18px, active 시 `--primary` 색상 + 하단 인디케이터 | 상단 GNB는 흰색 텍스트(어두운 배경), 메인 메뉴(LNB)는 검정 텍스트(흰 배경) |

**규칙:** 헤딩은 "오버라인 + 넓은 자간"으로 만들고, 본문·목록은 촘촘한 자간의 고딕으로 대비를 준다.

## 4. 레이아웃 원칙

1. **고정폭 1200px 중앙 정렬** — 헤더부터 본문·푸터까지 전부 1200px 컨테이너 기준.
2. **3단 헤더 구조** — ① 진남색 최상단 유틸바(70px, 로그인·SNS·전체메뉴) → ② 흰색 메인 내비바(80px, 로고 + 가로 메뉴, 얇은 보더로 분리) → ③ 본문은 옅은 민트그레이(`#EDF4F1`) 배경 위에 흰 카드들이 떠 있는 구조.
3. **카드 그리드 대시보드형 본문** — 히어로 이미지 배너 대신, "오늘의 일정(캘린더)", "보도자료(카드 슬라이더)", "위원회 구성", "법률·의안", "자료실"을 **동시에 볼 수 있는 카드 그리드**로 배치 — 정보 밀도가 높은 대시보드 스타일.
4. **부드러운 라운드 + 얕은 그림자** — 카드·검색창 라운드 10px, 작은 버튼·뱃지는 5px, 원형 버튼(이전/다음 화살표)은 50%. 그림자는 아주 옅게(`0 4px 4px rgba(0,0,0,.05)`), 드롭다운 메뉴만 조금 더 진하게(`0 0 10px rgba(0,0,0,.1)`).
5. **정보성 카드 + 명암 대비 최소화** — 마케팅형 사이트처럼 어두운 섹션·CTA 밴드를 쓰지 않는다. 전체적으로 밝은 톤 하나를 유지하고, 카드 내부의 색 뱃지로만 위계를 만든다.

## 5. 핵심 컴포넌트 패턴

- **섹션 제목:** "오버라인 3px + 자간 넓은 대문 텍스트 + 우측 더보기(+) 원형 버튼" 조합이 모든 콘텐츠 블록의 시작.
- **일정 리스트:** 좌측에 색상 뱃지(`.label_name`, 유형별 색상, 흰 텍스트, radius 5px) + 우측에 말줄임 처리된 제목 한 줄, 하단에 회색 보조 정보(날짜 등).
- **보도자료 카드:** 상단 이미지, 카드 상단에 네이비 아웃라인 뱃지(카테고리명), **카드 하단에 틸(청록) 색 바** + 흰 텍스트로 부서명·날짜 표시 — "이중 태그(아웃라인 + 채움 바)" 구조.
- **자료 카드(자료실 등):** 옅은 회색(`#F8F8F8`) 배경 카드 + 상단에 둥근 알약형(radius 15px) 컬러 태그 + 배경에 옅은 워터마크 이미지.
- **통합검색 바:** 폭 50%, 라운드 10px, 옅은 보더 + 얕은 그림자, placeholder 회색.
- **더보기 버튼:** 30×30 원형, 연회색(`#F4F4F4`) 배경에 `+` 아이콘, 호버 시 민트그린(`#d3ede2`) 배경으로 전환.
- **캐러셀 이전/다음:** 40×40 반투명 검정 원형 버튼, 호버 시 더 진해지며 5px 바깥으로 이동(hover 시 살짝 튀어나오는 마이크로 인터랙션).
- **푸터:** 상단 1px 보더(`#EAEAEA`)로 구분, 국회 로고 + 약관 링크 한 줄 + 주소·전화·이메일 + 저작권 문구 + 소관/유관 기관 홈페이지 바로가기 select 4개.

## 6. 완성 기준 (체크리스트)

- [ ] 최상단 진남색 유틸바 / 흰색 메인 내비바 2단 헤더 구조인가
- [ ] 본문 배경이 순백이 아니라 옅은 민트그레이(`#EDF4F1`)인가, 그 위에 흰 카드가 떠 있는가
- [ ] 섹션 제목이 "오버라인 + 넓은 자간" 패턴을 따르는가
- [ ] 카드·버튼의 라운드(10px/5px/50%)와 옅은 그림자가 일관되는가
- [ ] 유채색이 링크·상태 표시(블루)와 카테고리 뱃지(항목당 1색)로만 제한되는가 — 화면 전체가 다색으로 뒤덮이지 않는가
- [ ] 다량의 게시판·일정 정보를 카드 그리드로 동시에 노출해 정보 탐색성을 우선하는가 (마케팅형 히어로·CTA 밴드에 의존하지 않는가)

## 7. 금지 행동

- **국회 엠블럼(국회 상징 마크)·로고·기관명·공식 문구를 복제·재사용 금지** — 국가 기관의 공식 상징은 저작권과 별개로 사용 제한이 있다. 디자인 **원칙(레이아웃·색·타이포그래피 규칙)만** 참조한다.
- **원본 사이트의 실제 게시글·보도자료 내용·개인정보(위원 성명·연락처 등)를 그대로 복제해 예시 데이터로 쓰지 않는다** — 새 프로젝트에는 비식별 가상 데이터를 사용한다.
- **카테고리 뱃지 색을 화면 전체 배색으로 확장하지 않는다** — 이 팔레트는 "항목 구분용"이지 "브랜드 포인트 컬러"가 아니다. 과도하게 쓰면 신뢰감 있는 톤이 무너진다.
