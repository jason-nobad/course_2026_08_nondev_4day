# 금지 행동 — 주간 보고 초안 작성 (샘플)

> 📎 **샘플(가상 사례)** — 1일차 과제 "금지 행동 초안"의 예시입니다. **각 항목에 이유를 함께 적는 것**이 핵심입니다 — 이유가 있어야 다른 팀원(과 AI)이 경계를 이해합니다. 2일차에 스킬 v1.0 §6으로 들어갔습니다.

| # | 금지 행동 | 이유 (무엇이 잘못되나) | 대신 이렇게 |
|------|------|------|------|
| 1 | 메모가 없거나 빈 팀원의 업무를 **추정해서 채우기** | 보고서에 "하지 않은 일"이 생기고, 그대로 상위 보고에 올라간다 (환각) | `[미제출]` 표시 후 초안 생성 중단, 담당자에게 확인 요청 |
| 2 | 지연 **사유를 단정·추정**하기 ("담당자 태만", "타 부서 비협조") | 개인 평가로 읽혀 팀 신뢰를 해친다. 사실 확인 없는 원인 진단 | 메모에 적힌 사유만 옮기고, 없으면 `[확인 필요: 사유 없음]` |
| 3 | 금액·단가·수량·증감률 **계산**하기 | 계산 오류가 검증 없이 경영진 자료가 된다. 재무 수치는 원본 대조가 원칙 | 원문 그대로 옮기고 `[수치 원문 대조]` 태그 |
| 4 | 팀원 간 **성과 비교** 표현 ("A 5건 처리, B 1건 처리") | 주간 보고의 목적은 업무 현황 공유이지 인사 평가가 아니다 | 항목별 담당자 표기까지만 |
| 5 | **대외 공유 범위**를 임의로 정하거나 요약본을 만들어 배포하기 | 어떤 항목을 본부 회의에 올릴지는 팀장의 판단 | 초안에 항상 "팀장 승인 전 · 대외 공유 금지" 표시 |
| 6 | 입력에 **개인 연락처·계좌·실명 고객·실제 계약 금액**이 보이는데 계속 진행하기 | 비식별 원칙 위반. 저장소가 공개(Pages)되면 유출 | 즉시 중단하고 입력을 비식별 처리한 뒤 다시 실행 |
| 7 | 보고 양식의 **절 순서·제목을 바꾸기** | 팀장이 매주 같은 자리에서 같은 정보를 읽는다. 양식이 바뀌면 검토 시간이 늘어난다 | 양식 v3 그대로. 바꾸고 싶으면 스킬 개정으로 |
| 8 | 항목을 **문단으로 풀어 쓰기** | 개조식 1줄이 아니면 20개 항목이 2쪽이 된다 | 항목당 1줄, 40자 안팎 |
