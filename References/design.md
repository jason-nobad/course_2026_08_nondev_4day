# 스킬: Orderful 스타일 웹 디자인 (B2B SaaS 랜딩 페이지)

> **근거:** https://www.orderful.com/ 2026-08-16 실측 분석 (렌더링 스크린샷 + CSS 소스에서 추출한 실제 값)
> **활용:** 교육 과정의 홈페이지 실습(제2일)·디자인 스킬 작성 예시. 상표·로고·문구를 복제하지 말고 **디자인 원칙만** 참조할 것.

## 1. 목적과 사용자

- **목적:** 신뢰감(엔터프라이즈)과 속도감(스타트업)을 동시에 주는 B2B SaaS 랜딩 페이지를 만든다.
- **받는 사람:** 제품 도입을 검토하는 실무자·의사결정자 — 첫 화면에서 "무엇을, 얼마나 빨리"가 읽혀야 한다.

## 2. 색상 팔레트 (CSS에서 추출한 실제 값)

| 역할 | 값 | 사용처 |
|------|------|------|
| 시그니처 오렌지레드 | `#f32b09` (`--theme-orange`) | 주 CTA 버튼, 강조 배지, 포인트 그래픽 |
| 오렌지 그라데이션 | `#ff7802 → #ff5502 → #f32b09 → #c5280d` | 풀폭 CTA 밴드, 제품 일러스트 듀오톤 |
| 잉크(거의 검정) | `#080808` / `#1f1f1f` | 다크 섹션 배경, 보조 버튼, 본문 헤드라인 |
| 본문 그레이 | `#3b3b3b` / `#676767` / `#ababab` | 본문, 캡션, 비활성 |
| 서피스 | `#ffffff` 카드 / `#f7f7f7`·`#f5f5f5` 페이지 배경 | 흰 카드가 연회색 바탕 위에 뜨는 구조 |
| 라인 | `#ebebeb` / `#e0e0e0` | 얇은 1px 보더, 카드 구분 |

**규칙:** 유채색은 사실상 **오렌지레드 하나**만 쓴다(단색 포인트 전략). 나머지는 전부 무채색 — 색을 늘리는 대신 명도 대비로 위계를 만든다.

## 3. 타이포그래피

| 용도 | 서체 | 특징 |
|------|------|------|
| 헤드라인 | **PP Telegraf** (`--font-telegraf`) | 기하학적 그로테스크. 매우 크게(히어로 약 64–80px), 문장형 대소문자, 행간 타이트 |
| 본문 | Modern Gothic (`--font-gothic`) / 산세리프 | 16–18px, 회색 `#3b3b3b` |
| 라벨·버튼·내비 | **모노스페이스 대문자** (`--font-mono`) | `BOOK A DEMO`, `THE LEADER IN EDI` — 작은 크기 + 자간 넓게. 기술 제품 느낌의 핵심 장치 |

**규칙:** "큰 문장형 헤드라인 + 작은 모노 대문자 아이브로(eyebrow)" 조합이 모든 섹션의 기본 리듬.

## 4. 레이아웃 원칙

1. **패널 스택 구조** — 페이지는 흰색(또는 검정·오렌지) 풀폭 패널을 세로로 쌓고, 패널 사이에 연회색 배경이 살짝 보이는 좁은 홈을 둔다.
2. **큰 라운드** — 카드·버튼·이미지 모두 큰 모서리 반경(카드 16–24px). 날카로운 모서리 없음.
3. **넉넉한 여백** — 섹션 상하 패딩을 크게(120px±), 텍스트 컬럼은 좁게 유지해 헤드라인이 숨 쉬게 한다.
4. **명암 리듬** — 흰 섹션 여러 개 → 검정 섹션(신뢰 지표) → 흰 섹션 → 오렌지 그라데이션 CTA 밴드 → 흰 푸터. 어두운 섹션이 페이지 중간과 끝 직전에 한 번씩.

## 5. 핵심 컴포넌트 패턴

- **히어로:** 좌측 텍스트(헤드라인 + 2줄 서브카피 + 주 CTA 1개) / 우측 제품 그래픽(다크 대시보드 + 오렌지 글로우). CTA는 오렌지 바탕 + 흰 모노 대문자.
- **로고 캐러셀:** "Trusted by …" 한 줄 + 고객 로고 흑백 나열 — 히어로 바로 아래.
- **수상 배지 열:** G2 배지처럼 작은 카드 5개를 가로 나열해 제3자 검증 제시.
- **제품 카드 3열:** 아이콘 + 제품명(굵게) + 3–4줄 설명 + "Learn more →" + 오렌지 듀오톤 스크린샷.
- **통계 카드:** 큰 숫자(Telegraf, 48px+) + 작은 회색 캡션. 3–5개 나열. 다크 섹션에서는 흰 숫자.
- **고객 후기 카드:** 인물 사진 + 이름·직함 + 인용문(핵심 구절만 **굵게**) + 하단 통계 3개 + 우측 브랜드 컬러 이미지. 페이지네이션 번호(1 2 3).
- **수직 탭 아코디언:** 산업별 솔루션을 세로로 세운 탭(회전된 라벨)으로 배치 — 펼친 탭만 내용 표시.
- **CTA 밴드:** 오렌지 그라데이션 풀폭 + 흰 대형 헤드라인 + 짧은 슬로건 + 검정(또는 흰) 버튼 1개.
- **푸터:** 흰 배경, 로고 + 5열 링크 그리드 + 뉴스레터 폼 + 소셜 아이콘.

## 6. 이미지·일러스트 스타일

- 실제 스크린샷을 그대로 쓰지 않고 **오렌지 듀오톤으로 단순화한 목업**으로 통일.
- 다크 그래픽에는 오렌지레드 글로우(네온 테두리)로 시선 유도.
- 고객 로고는 흑백, 파트너 로고(ERP·플랫폼)만 원색 허용 — 색의 소유권을 자사 오렌지에 남긴다.

## 7. 완성 기준 (체크리스트)

- [ ] 유채색이 오렌지레드 계열 하나로 제한되는가
- [ ] 모든 섹션이 "모노 대문자 아이브로 → 큰 헤드라인 → 짧은 본문 → CTA" 리듬을 따르는가
- [ ] 다크 섹션·오렌지 CTA 밴드로 명암 리듬이 만들어지는가
- [ ] 카드·버튼의 라운드와 보더(`#ebebeb`)가 일관되는가
- [ ] 주장마다 숫자(통계)나 제3자 검증(로고·배지·후기)이 붙는가
- [ ] CTA 문구가 페이지 전체에서 1종("Book a Demo")으로 통일되는가

## 8. 금지 행동

- **Orderful의 로고·상표·카피 문구·고객 로고를 복제 금지** — 디자인 원칙만 참조한다(저작권·상표권).
- 포인트 색 2개 이상 추가 금지 — 단색 포인트 전략이 무너진다.
- 근거 없는 통계 삽입 금지 — 이 스타일은 숫자가 많아 과장 시 신뢰가 함께 무너진다.
