# Orderful(orderful.com) 사이트 정보 요약

> 용도: 디자인 스킬([design.md](design.md))의 배경 정보 — 어떤 회사의 사이트를 분석했는지 기록

## 한 줄 소개

**Orderful**은 기업 간 전자문서교환(**EDI, Electronic Data Interchange**)을 클라우드로 제공하는 미국 B2B SaaS 플랫폼이다. 슬로건은 "The Fastest Way to Trade EDI" — 소매·물류 공급망에서 거래처(트레이딩 파트너) 연동을 빠르게 해 주는 것이 핵심 가치다.

## 주요 제품 (3종)

| 제품 | 내용 |
|------|------|
| **Mosaic** (Integrated EDI API) | AI 기반 EDI API — 자동 매핑·테스트·검증으로 "10배 빠른 통합"을 내세움 |
| **Pixel** (Web EDI) | 웹 화면만으로 어떤 규모의 파트너와도 즉시 EDI 거래 — 비개발 조직용 |
| **Shipping Labels** | 소매 유통망 납품용 UCC-128/GS1 라벨·패킹 슬립 생성 |

## 내세우는 수치·신뢰 요소

- 네트워크: 거래 파트너 10,000+ · 트랜잭션 50M+ · 가동률 99.99% · SOC 2 인증
- 사례: 온보딩 기간 50% 단축(KBX), EDI 비용 70% 절감(Liquid Death), 신규 파트너 온보딩 5일 미만(NFI)
- G2 어워드 배지(Leader, Momentum Leader 등)를 홈에 전면 배치
- 고객사: Liquid Death, Pabst, Bridgestone, Oura, ShipBob, NFI 등 / 연동: NetSuite·SAP·Dynamics(ERP), Shopify·QuickBooks(플랫폼), Trimble·Blue Yonder(TMS/WMS)

## 대상 산업

소매(Retail), 물류(Logistics)·운송사(Carriers)·3PL, 식음료(F&B), 제조(Manufacturing), SaaS/테크 플랫폼

## 페이지 구성 (위→아래)

내비게이션 → 히어로(헤드라인+데모 CTA+대시보드 그래픽) → 고객 로고 캐러셀 → G2 배지 → 제품 3카드 → 다크 신뢰 지표 섹션 → 연동 생태계 → 고객 후기(수치 3종 포함) → 산업별 수직 탭 → 오렌지 CTA 밴드 → 푸터. 가격은 비공개("Book a Demo" 유도).
