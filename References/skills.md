# 스킬: KS A 0001 기반 표준 문서 작성

> **근거 문서:** KS A 0001:2020 — 표준의 서식과 작성 방법 (ISO/IEC Directives, Part 2 제8판 기초)
> **출처:** `KSA0001_20210105.pdf` (신구 비교표 재구성본). 비공식 발췌 기반이므로 공식 인용 시 e나라표준인증의 원문을 대조할 것.

## 1. 목적과 사용자

- **목적:** 표준 문서를 KS A 0001:2020의 서식·표현 규칙에 맞게 작성한다. 이 표준은 국가표준의 구성·표현 형식을 규정하며 한국산업표준뿐 아니라 **단체표준, 회사표준, 기술기준에도 적용 가능**하다.
- **결과물을 받는 사람:** 표준 심의 위원회, 표준 사용자(설계·품질·구매 담당), 인증·감사 기관.

## 2. 입력

- 표준화 대상(주제)과 적용범위 초안
- 인용할 기존 표준 목록(KS·ISO·IEC 번호와 발행연도)
- 용어 후보와 정의 초안
- **KS Draft Template** — 표준 준비 시 국가기술표준원이 제공하는 표준 작성용 프로그램을 **사용하여야 한다** (e나라표준인증 www.standard.go.kr 에서 제공).

## 3. 작업 절차

1. **명칭 작성** — 3요소 구조로 작성한다: **도입요소**(선택) + **주요소**(필수) + **보완요소**(선택). 여러 부(part)로 나뉘는 표준은 각 부의 도입요소·주요소는 동일하게, **보완요소만 서로 다르게** 하고 보완요소 앞에 "제…부"를 선행시킨다. 앞표지에 영문 명칭을 병기하고 **국제표준분류코드(ICS)** 를 표시한다(주요소·보완요소 기준으로 선정, 일반적으로 2개까지, 구분자는 세미콜론).
2. **요소 순서대로 구성** — §4의 문서 구성 순서를 따른다.
3. **적용범위 작성** — 이 표준이 무엇을 규정하고 무엇에 적용되는지 간결히 서술한다. 적용범위에는 요구사항을 두지 않는다.
4. **인용표준 목록 작성** — §5.1의 정형문으로 도입한다.
5. **용어와 정의 작성** — §5.2의 정형문으로 도입하고, 항목별 번호(3.1, 3.2…)를 부여한다.
6. **본문(요구사항) 작성** — 조항 표현 규칙(§6)의 조동사 구분을 엄격히 적용한다. 시험방법·샘플링·분류/호칭·표기/라벨링은 해당 시 의무요소 구조(6.3.x)를 따른다.
7. **부속서 배치** — 규정 내용은 **부속서(규정)**, 참고 내용은 **부속서(참고)** 로 명시해 구분한다.
8. **번호·참조 정리** — 절(clause)·항(subclause: 5.1, 5.1.1)·문단·목록의 구분과 번호 붙이기를 점검하고, 문서 내 참조와 타 표준 참조 표기(§7)를 통일한다.
9. **완성 기준 체크리스트(§9)로 자체 검증** 후 심의에 제출한다.

## 4. 문서 구성 (요소와 순서)

| 순서 | 요소 | 구분 |
|------|------|------|
| 1 | 앞표지 (영문 명칭·ICS 코드 포함) | 의무 |
| 2 | 목차 | 조건 |
| 3 | 머리말 | 의무 (정형문) |
| 4 | 개요 | 선택 |
| 5 | 명칭 | 의무 |
| 6 | 1 적용범위 | 의무 |
| 7 | 2 인용표준 | 선택(인용 시 의무) |
| 8 | 3 용어와 정의 | 조건 |
| 9 | 기호와 약어 | 조건 |
| 10 | 본문 — 요구사항 · 샘플링 · 시험방법 · 분류/호칭/부호화 · 표기/라벨링/포장 | 의무/조건 |
| 11 | 부속서(규정) | 조건 |
| 12 | 부속서(참고) | 조건 |

| 14 | 색인 · 해설 | 선택 |

요소 유형 구분: **의무요소**(반드시 존재), **조건요소**(특정 조항 존재 시 의무), **선택요소**(작성자가 포함 여부 선택).

## 5. 정형문 (고정 문구 — 그대로 사용)

### 5.1 인용표준 도입부

> "다음의 인용표준은 전체 또는 부분적으로 이 표준의 적용을 위해 필수적이다. 발행연도가 표기된 인용표준은 인용된 판만을 적용한다. 발행연도가 표기되지 않은 인용표준은 최신판(모든 추록을 포함)을 적용한다."

### 5.2 용어와 정의 도입부

> "이 표준의 목적을 위하여 다음의 용어와 정의를 적용한다."

(비고로 ISO OBP, IEC Electropedia, e나라표준인증 KS용어사전 참조를 안내할 수 있다.)

## 6. 조항 표현 규칙 — 조동사 구분 (가장 중요)

조항(provision)의 성격에 따라 문말 표현을 엄격히 구분한다. 잘못 섞으면 요구·권고의 구속력이 달라진다.

| 조항 유형 | 의미 | 한국어 표현 |
|------|------|------|
| **요구사항** (requirement) | 준수가 요구되며 일탈이 허용되지 않음 | "~하여야 한다", "~해야 한다" / 금지: "~해서는 안 된다" |
| **권고사항** (recommendation) | 여러 가능성 중 특히 적합한 것을 제시 | "~하는 것이 좋다" |
| **허용** (permission) | 하는 것에 대한 동의·자유를 전달 | "~하여도 된다", "~해도 된다" |
| **가능성·역량** (possibility·capability) | 예상되는 결과나 능력을 전달 | "~할 수 있다" |
| **설명** (statement) | 정보 전달 표현 | 평서문 ("~이다", "~한다") |

## 7. 참조·인용 표기 규칙

- **일자(연도)가 명시된 참조:** 해당 판만 적용. 특정 조항·표를 인용할 때는 반드시 연도를 명시한다.
- **일자가 명시되지 않은 참조:** 전체 표준(또는 한 부)을 참조할 때만 가능하며, **추록·개정판을 포함한 최신판을 적용하는 것으로 간주**된다. 형식 보기: "…KS A ISO 128-21 및 KS A ISO 80000…에서 규정된 대로", "…KS C IEC 60027 참조…"
- **인용표준 목록에 넣어서는 안 되는 것:** ① 공적으로 유효하지 않은 문서 ② 정보 제공 목적으로만 인용되는 문서 ③ 준비 과정의 배경자료 — 이들은 **참고문헌**에 등재한다.

## 8. 비고·보기·각주 / 수치·단위 규칙

- **비고(note)와 보기(example)에는 요구사항을 포함하지 않는다** — 참고 정보만 담는다. 요구사항은 본문 조항으로 승격시킨다.
- 같은 절·항에 여러 개가 있으면 "비고 1, 비고 2…", "보기 1, 보기 2…"로 번호를 붙인다. 라벨(비고·보기)은 **굵은 활자체**로 표시하며, 동일 조항에 비고와 보기가 함께 있으면 **보기를 먼저** 배치한다.
- **단위:** KS A ISO 80000·KS A IEC 80000 계열의 **SI 단위만 사용**한다. 허용된 병용 단위: 분(min)·시(h)·일(d)·도(°)·리터(L)·톤(t)·전자볼트(eV)·돌턴(Da) 등 (KS A ISO 80000-1 표 5·6).
- 국제표준 부합화 시 소수점 쉼표(,)→마침표(.) 변경, 오탈자 수정, "이 국제표준"→"이 표준" 치환 등은 **편집상 변경**으로 기술적 차이에 해당하지 않는다.

## 9. 출력 완성 기준 (검증 체크리스트)

- [ ] KS Draft Template로 작성했는가
- [ ] 명칭이 도입요소·주요소·보완요소 구조를 따르는가 (부 분할 시 "제…부" 선행)
- [ ] 앞표지에 영문 명칭과 ICS 코드(≤2개, 세미콜론 구분)가 있는가
- [ ] 의무요소(명칭·적용범위·요구사항 등)가 모두 존재하는가
- [ ] 인용표준·용어와 정의가 §5의 정형문으로 도입되는가
- [ ] 모든 조항의 문말 표현이 §6의 조동사 구분과 일치하는가 (요구↔권고 혼용 없음)
- [ ] 비고·보기에 요구사항("하여야 한다")이 숨어 있지 않은가
- [ ] 일자 미명시 참조가 "전체 표준 참조 + 최신판 적용 허용" 조건을 만족하는가
- [ ] 인용표준 목록에 정보용·배경자료가 섞여 있지 않은가 (→ 참고문헌으로)
- [ ] 계약 관련 요구사항(청구·보증·비용)과 법령·법규 요구사항이 포함되지 않았는가
- [ ] 부속서마다 (규정)/(참고) 구분이 명시됐는가
- [ ] 단위가 SI(+허용 병용 단위)만 사용됐는가

## 10. 금지 행동 (이유와 함께)

- **비고·보기에 요구사항 서술 금지** — 구속력의 소재가 불명확해진다. 요구사항은 본문 조항으로.
- **계약·법령상 요구사항 포함 금지** — 표준은 계약 요구사항(청구·보증·비용 충당 등)과 법령·법규가 정한 요구사항을 포함하지 않아야 한다.
- **조동사 임의 혼용 금지** — "~하는 것이 좋다"(권고)를 요구사항 의도로 쓰거나, "~할 수 있다"(가능)를 허용 의도로 쓰지 않는다.
- **SI 외 단위 사용 금지** — 허용 병용 단위 외 관용 단위(평, 근 등)를 쓰지 않는다.
- **유효하지 않은 문서의 인용표준 등재 금지** — 참고문헌으로만.
- **반복 서술 금지** — 동일 요구사항을 여러 곳에 반복하지 않는다(반복의 회피 원칙). 한 곳에 규정하고 나머지는 참조한다.
