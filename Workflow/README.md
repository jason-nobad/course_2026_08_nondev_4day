## 흐름도 만드는 법

Claude에게 업무 순서를 말로 설명하면 Mermaid 도식을 만들어 줍니다. 아래처럼 마크다운 파일에 붙여 넣으면 GitHub 화면에서 그림으로 보입니다.

```mermaid
flowchart LR
    A[입력 취합] --> B[AI 초안 작성]
    B --> C{담당자 검토<br/>승인 게이트}
    C -- 승인 --> D[발송·공유]
    C -- 수정 요청 --> B
    C -- 판단 불가 --> E[팀장 에스컬레이션]
```

- **승인 게이트**는 반드시 이름 또는 역할로 표시합니다 (예: "팀장 검토").
- 외부(고객·타 부서)로 나가는 산출물 앞에는 예외 없이 사람의 승인이 있어야 합니다.
