## 예외 경로 — 잘못됐을 때 누가 무엇을

| 예외 상황 | 감지 | 1차 조치 (누가) | 2차 조치 (누가) | 기록 |
|------|------|------|------|------|
| 승인본에 **사실 오류** 발견 (예: 완료 아닌 항목이 완료로) | 팀원·팀장 | 이하늘 — 팀 채널에 정정 공지, `03_final`에 v2 저장(원본 삭제 금지) | 김가온 — 본부 발췌분이면 본부에 정정 통보 | 검증 체크리스트에 실패 사례 추가 |
| 초안에 **개인정보·실데이터** 포함 | 도구(패턴) 또는 사람 | 이하늘 — 즉시 중단·삭제, 저장소 커밋 이력 확인 | 김가온 — IT·보안 담당에 통보, **중단 조건 발동 검토** | 사고 기록 + 스킬 금지 6-6 보강 |
| **지연 사유가 사실과 다름** (메모 오기) | 해당 팀원 | 해당 팀원 — 메모 수정 → 도구 재실행(v2) | 이하늘 — 승인 전이면 교체, 승인 후면 정정 공지 | 변경 이력(커밋)에 남음 |
| **도구가 멈추지 않고** 잘못된 초안 생성 (오류 샘플이 통과) | 자체 점검 | 이하늘 — 도구 사용 중단, 수동 작성 | 박서준 — Claude Code로 수리 후 3종 재검증 | USAGE 검증 기록 갱신 |
| 팀장 **부재**로 승인 불가 | 금 15:00 | 선임 대리 대행 승인 (대행 게이트) | 김가온 — 다음 근무일 사후 확인 | 승인란에 "대행" 표기 |
| 초안 내용이 **팀 밖으로 유출** (승인 전) | 누구나 | 이하늘 — 경위 파악, 팀장 보고 | 김가온 — 필요 시 본부에 "미승인 초안" 고지 | 사고 기록 |
