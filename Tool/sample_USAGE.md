# 주간 보고 초안 취합 도구 — 사용법과 검증 기록 (샘플)

> 📎 **샘플(가상 사례)** — 3일차 실습에서 Claude Code로 만든 "업무용 프로그램"의 사용법 문서 예시입니다. 도구 본체: [`sample_weekly_report_tool.py`](sample_weekly_report_tool.py)

## 한 줄 명세

**팀원 업무 메모(memo_이름.md)들을 넣으면 → 완료/진행/지연/다음 주/이슈로 취합하고, 지난주 보고와 비교해 변경점을 표시하고, 지연 사유 누락·수치·미제출을 "검토 필요"로 표시해서 → 팀장 승인 전 초안 파일이 나온다.**

| 항목 | 내용 |
|------|------|
| 용도 | 매주 금요일 오전 주간 보고 초안 취합 (스킬 `Skills/sample_weekly-report.md`의 절차 1~7을 자동화) |
| 입력 | `_workspace/01_input/<케이스>/memo_이름.md` (팀원별 1개) · `_workspace/01_input/*last_week_report_*.md` (지난주 승인본, 가장 최신 것 자동 선택) |
| 출력 | `_workspace/02_working/YYYY-MM-DD_주간보고초안_v번호.md` (같은 날짜로 다시 돌리면 v2, v3… 자동 증가) |
| 실행 환경 | 파이썬 3 (macOS·Windows 기본 설치 또는 python.org). 외부 설치 없음 |
| 전제 조건 | 메모는 `## 완료 / ## 진행 / ## 지연 / ## 다음 주 / ## 이슈` 절 아래 `- 항목` 형식. 지연 항목은 `— 사유: …` 포함 |

## 실행 방법

저장소 루트 폴더에서 (Claude Code에게 "아래 명령을 실행해 줘"라고 말해도 됩니다):

```bash
python3 Tool/sample_weekly_report_tool.py sample_normal --date 2026-08-14
```

- `sample_normal` 자리에 `_workspace/01_input/` 아래 폴더 이름을 넣습니다. 실무에서는 예: `2026-08-21`
- `--date`는 보고 대상 주의 **금요일**. 생략하면 오늘 날짜
- `--members 이하늘,박서준,최유진` 으로 제출 대상 팀원을 바꿀 수 있습니다

**멈추는 경우(초안을 만들지 않음):** 메모 파일이 없음 · 메모가 비어 있음 · 절 제목을 못 찾음 · 휴대폰·주민번호·이메일·카드번호 패턴이 보임 → 화면에 이유를 출력하고 종료. 입력을 고친 뒤 다시 실행.

**표시만 하고 계속하는 경우(초안 하단 "검토 필요 항목"에 기록):** 팀원 미제출 · 지연 항목 사유 없음 · 수치(금액·단가·%) 포함 항목 · 한 사람의 한 절에 9건 이상.

## 알려진 한계 (스킬 개정 시 참고)

- 지난주 대비 변경점은 **문구 비교**로 찾습니다. 지난주 "한빛부품 9월분 PO 발행"이 이번 주 "한빛 PO 완료"처럼 표현이 크게 바뀌면 못 잡습니다 → 메모에 지난주와 같은 표현을 쓰는 것을 팀 규칙으로.
- 개인정보 탐지는 **형식 패턴**(번호 모양)만 봅니다. 사람 이름·회사 기밀 문장은 못 잡습니다 → 비식별 원칙은 사람이 지켜야 합니다.
- 수치 태그는 "숫자 + %·원" 또는 "숫자가 있는 단가·금액·견적 문장"에만 붙습니다. 수량(개·건)은 태그하지 않습니다.
- 도구는 메모 문구를 **그대로** 옮깁니다. 문맥 보강("무엇의 검사인지")은 사람이 합니다 (`03_final` 검토 반영 내역 참조).
