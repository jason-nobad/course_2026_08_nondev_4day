# _workspace/ — 폴더 규칙 (원본 / 작업 중 / 최종)

"내가 자리에 없어도, 폴더만 열면 누구든 같은 결과를 다시 만들 수 있는 상태"를 만드는 작업 공간입니다.
3일차 실습 2에서 이 문서를 우리 팀 규칙으로 완성합니다.

## 폴더 구조

| 폴더 | 무엇이 들어가나 | 규칙 |
|------|------|------|
| `01_input/` | **원본(입력)** — 비식별 샘플 데이터, 업무 양식 샘플 | 손대지 않는다. 바꿔야 하면 복사해서 `02_working/`에서 |
| `02_working/` | **작업 중** — AI 초안, 중간 산출물 | 파일 이름에 날짜·버전 (예: `2026-08-20_보고초안_v2.md`) |
| `03_final/` | **최종** — 사람이 검토·승인한 결과물만 | 승인자와 승인일을 파일 안 또는 이름에 남긴다 |

## 우리 팀 규칙 (3일차에 채우기)

- **이름 규칙:** (예: `YYYY-MM-DD_업무명_v번호.확장자`)
- **보존 규칙:** (예: 작업 중 파일은 최종 확정 후 30일 보관 뒤 삭제)
- **접근 규칙:** (예: `03_final/`은 승인자만 수정, 나머지는 읽기)
- **금지 데이터:** 고객 실명 · 실제 계약 금액 · 개인정보 · 사내 기밀 — 가명·더미 값만

> ⚠️ 이 저장소는 GitHub Pages로 **공개**됩니다. `_workspace/` 안에도 반드시 **비식별 샘플만** 두세요.
