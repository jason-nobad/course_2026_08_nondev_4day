# 01_input 샘플 안내 (가상 사례: ㈜가온물산 구매팀 주간 보고)

> 📎 이 폴더의 `sample_*`는 3일차 "샘플 3종 검증"을 그대로 재현할 수 있게 만든 **비식별 더미 데이터**입니다. 실습 시 본인 업무의 샘플로 바꾸세요.

| 파일/폴더 | 무엇 | 용도 |
|------|------|------|
| `sample_report_template.md` | 보고 양식 v3 | 스킬 §4 출력 형식의 근거 |
| `sample_last_week_report_2026-08-07.md` | 지난주 승인본 | 변경점(◀ 진행→완료, ⚠ 2주 연속 지연) 표시용 |
| `sample_normal/` | **정상** — 팀원 3명 메모 모두 제출, 형식 정상 | 도구가 초안을 만들어야 함 |
| `sample_edge/` | **경계** — 최유진 미제출 · 이하늘 지연 사유 없음 · 박서준 완료 12건 | 도구가 ⚠ 표시를 달고 초안을 만들되, 검토 필요 항목에 올려야 함 |
| `sample_error/` | **오류** — 이하늘 메모 0바이트 · 박서준 메모에 연락처·주민번호 패턴(더미) | 도구가 **초안을 만들지 않고 멈춰야** 함 |

실행: 저장소 루트에서 `python3 Tool/sample_weekly_report_tool.py sample_normal --date 2026-08-14` (자세한 사용법은 `Tool/sample_USAGE.md`)
