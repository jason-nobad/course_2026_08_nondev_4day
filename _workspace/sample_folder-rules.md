# _workspace 폴더 규칙 — 구매팀 주간 보고 (샘플)

> 📎 **샘플(가상 사례)** — 3일차 실습 2 "_workspace 규칙" 문서의 예시입니다. `README.md`의 "우리 팀 규칙 (3일차에 채우기)"를 채운 모습입니다.

## 폴더 트리

```
_workspace/
├── 01_input/                         원본 — 손대지 않음
│   ├── sample_report_template.md          보고 양식 v3
│   ├── sample_last_week_report_YYYY-MM-DD.md   지난주 승인본 (매주 03_final에서 복사해 둔다)
│   └── <케이스>/memo_이름.md               팀원 메모 (금요일 11:00까지 각자 저장)
├── 02_working/                       작업 중 — 도구가 만든 초안, 담당자 수정본
│   └── YYYY-MM-DD_주간보고초안_v1.md, _v2.md …
└── 03_final/                         최종 — 팀장 승인본만
    └── YYYY-MM-DD_주간보고_최종.md
```

## 우리 팀 규칙

| 항목 | 규칙 |
|------|------|
| **이름 규칙** | 날짜는 보고 대상 주의 **금요일** `YYYY-MM-DD` · 초안은 `_주간보고초안_v번호` · 승인본은 `_주간보고_최종` · 메모는 `memo_이름.md` |
| **원본 보호** | `01_input/`은 수정 금지. 메모를 고쳐야 하면 팀원이 자기 메모를 다시 저장(덮어쓰기)하고 도구를 재실행 |
| **버전** | 도구를 다시 돌리면 `v2`, `v3`… 자동 증가. 사람이 손으로 고친 파일도 새 번호로 저장(이전 버전 삭제 금지) |
| **보존** | `02_working/`은 승인 후 4주 보관 뒤 삭제 · `03_final/`은 1년 보관 · `01_input/` 메모는 해당 주 승인 후 4주 |
| **접근** | `03_final/` 저장은 팀장 승인 후 담당자(이하늘)만 · 나머지 폴더는 팀원 모두 읽기·쓰기 |
| **금지 데이터** | 협력사 담당자 실명·연락처, 계좌, 실제 계약 금액·단가표, 개인 평가 내용 — 발견 즉시 삭제 후 도구 재실행 |
| **재현 가능성 점검** | 승인본마다 "어떤 입력(메모 3건 + 지난주 보고)으로 어떤 초안(v번호)을 만들었는지"가 폴더만 보고 추적돼야 한다 |
